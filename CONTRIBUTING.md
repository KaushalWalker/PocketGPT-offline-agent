# Contributing to PocketGPT

Thank you for your interest in PocketGPT!

PocketGPT is an open-source, privacy-first AI companion designed to work locally without relying on cloud AI services.

Contributions of all experience levels are welcome.

## Ways to contribute

- Fix bugs and improve reliability.
- Improve the user interface and accessibility.
- Add features for reading, vocabulary, and English learning.
- Improve offline speech recognition and text-to-speech.
- Optimize local model performance.
- Improve documentation, examples, and tests.
- Help develop the future Android version.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes and test them locally.
4. Open a pull request explaining what you changed and why.

For larger features, please open a GitHub Issue first so we can discuss the approach.

## Project principles

- Keep AI inference local and privacy-focused.
- Avoid mandatory cloud services and accounts.
- Prefer simple, maintainable solutions.
- Keep the application accessible to people using ordinary hardware.
- Never commit personal chat histories, credentials, or downloaded model weights.

## Community

Be respectful, constructive, and welcoming to contributors of all skill levels.
